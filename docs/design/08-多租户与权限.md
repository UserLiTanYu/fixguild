# 9. 多租户与权限

> 所属：[总体设计](00-总体设计.md) · 原文章节：§9

## 9.1 租户上下文

```java
public final class TenantContext {

    private static final ThreadLocal<String> TENANT = new ThreadLocal<>();
    private static final ThreadLocal<Boolean> IGNORE = ThreadLocal.withInitial(() -> false);

    public static void set(String tenantId) {
        TENANT.set(tenantId);
    }

    public static String get() {
        return TENANT.get();
    }

    public static boolean isIgnore() {
        return Boolean.TRUE.equals(IGNORE.get());
    }

    public static void ignore() {
        IGNORE.set(true);
    }

    public static void clear() {
        TENANT.remove();
        IGNORE.remove();
    }
}
```

`TenantFactory`：

```java
@Component
public class MyTenantFactory implements TenantFactory {

    @Override
    public Object[] getTenantIds() {
        if (TenantContext.isIgnore()) {
            return null;
        }
        String tenantId = TenantContext.get();
        return tenantId == null ? null : new Object[]{tenantId};
    }
}
```

## 9.2 租户上下文来源

| 场景 | tenantId 来源 |
|---|---|
| 平台端 HTTP | `'0'`，跨租户方法用 `@IgnoreTenant` |
| 租户端 HTTP | 登录会话中的 `tenantId` |
| 技师端 HTTP | 登录会话中的 `tenantId` |
| MQ 消费 | 消息体 `tenantId`，消费前 `TenantContext.set()` |
| 定时任务 | 任务参数或遍历租户，显式 `set()` |
| 异步线程 | 父线程捕获，`TaskDecorator` 传递 |

> 关键：**不要在 `TenantFactory` 里硬编码租户 ID**。原项目 `MyTenantFactory` 目前返回固定值，学习时要改成真正的请求级隔离，并补测试。

> 平台端按租户查看数据时：使用 `@IgnoreTenant` 关闭自动租户过滤，再手动追加 `tenant_id = 请求参数`，并校验平台权限；不要直接查全表。

## 9.3 认证

- Sa-Token `loginId = userCode`；
- `device = clientCode`（`platform/tenant/technician`）；
- Header `satoken` 传 token；
- 拦截器校验：
  1. 白名单直接放行；
  2. 取 `client-code`，校验枚举；
  3. `StpUtil.checkLogin()`；
  4. token 的 device 必须等于 `client-code`；
  5. 从会话取 `tenantId`，写入 `TenantContext`；
  6. 写 MDC：`userCode/tenantId/clientCode`；
  7. token 剩余有效期 < 30 分钟时续期。

## 9.4 RBAC

- `sys_user` 关联 `sys_role`（通过 `sys_user_role`）；
- `sys_role` 关联 `sys_menu`（通过 `sys_role_menu`）；
- `sys_menu.perms` 存权限串，例如 `tenant:work-order:assign`；
- 接口用 `@SaCheckPermission("tenant:work-order:assign")`；
- `StpInterfaceImpl` 从 `AuthService` 拿权限列表。

## 9.5 权限缓存

不要每次鉴权都查库。推荐“版本号 + 缓存”：

```text
auth:version:{clientCode}:{tenantId}   -> 整数版本号
auth:info:{clientCode}:{tenantId}:{userCode}:{version} -> AuthInfo
```

- 登录/鉴权时先读版本号，再拼 key；
- 角色/菜单变更时 `INCR auth:version:{clientCode}:{tenantId}`；
- 旧版本 key 自然过期，不需要 `SCAN` 删除；
- TTL 30 分钟，兜底。

## 9.6 数据权限

| 角色 | data_scope | 规则 |
|---|---|---|
| 平台管理员 | 1 | 全部租户，`@IgnoreTenant` |
| 租户管理员/调度员 | 2 | 本租户 |
| 技师 | 3 | 本租户 + `technician_id = 自己` |
| 客户（二期） | 4 | 本租户 + `customer_id = 自己` |

技师端查询强制追加：

```java
query.and(WORK_ORDER.TECHNICIAN_ID.eq(currentTechnicianId()));
```
