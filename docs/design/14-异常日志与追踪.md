# 15. 异常、日志、追踪

> 所属：[总体设计](00-总体设计.md) · 原文章节：§15

## 15.1 响应码

| code | 含义 |
|---|---|
| 0 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 409 | 冲突/并发修改/重复请求 |
| 429 | 限流 |
| 500 | 系统异常 |
| 501 | 登录过期（沿用原项目约定） |

## 15.2 异常处理

- `BusinessException(code, msg)`：业务异常；
- `GlobalExceptionHandler`：
  - 参数校验 → 400 + 字段错误；
  - 业务异常 → 对应 code；
  - Sa-Token 异常 → 401/403/501；
  - 未知异常 → 500，日志打堆栈，响应不暴露堆栈；
- 所有异常响应带 `traceId`。

## 15.3 日志与 TraceId

- `TraceIdFilter`：
  - 读取 `X-Trace-Id`，没有则生成 ULID；
  - 写入 MDC：`traceId/tenantId/userCode/clientCode`；
  - 响应头返回 `X-Trace-Id`；
  - 请求结束清理 MDC。
- Logback pattern：

```text
%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level [%X{traceId}] [%X{tenantId}] [%X{userCode}] %logger{36} - %msg%n
```

- 线程池用 `TaskDecorator` 传递 MDC；
- MQ 消息体带 `traceId`，消费者写入 MDC；
- Job 每次执行生成 `traceId`；
- 慢 SQL：MyBatis-Flex `AuditManager` 记录 >500ms 的 SQL。
