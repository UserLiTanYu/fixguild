# M2：登录与权限

> 里程碑：M2 · 状态：进行中 · 预计 1 周  
> 关联设计：[08-多租户与权限](../design/08-多租户与权限.md) · [06-API设计](../design/06-API设计.md) · [13-安全与审计](../design/13-安全与审计.md)

---

## 1. 目标

完成三端登录闭环、RBAC、接口权限和数据范围，保证：

- 平台、租户、技师三个登录端互不串用；
- 租户 A 无法访问租户 B 的数据；
- 无权限接口返回 403；
- 权限模型能支撑 M3 的工单接口和技师数据范围。

---

## 2. 范围

- 角色菜单绑定、用户角色绑定；

- 平台/租户/技师数据范围规则；

### 不做

- 操作日志 AOP（M5）；
- 技师档案与工单数据范围（M3 落地）；
- 客户 H5（M7）。

## 4. 任务清单

### 4.1 登录与账号补全

- [x] 平台创建租户时同步创建初始管理员
  - `POST /platform/api/tenant/create` 增加 `adminUsername`、`adminNickname`
  - 租户、管理员同事务创建；初始密码只在响应中返回一次，数据库存 BCrypt
  - 默认管理员角色与菜单绑定随 4.2 RBAC 表落地后补齐
- [ ] 技师端登录 `POST /account/api/technician/login`
  - 请求参数：`tenantCode`、`username`、`password`
  - 校验 `sys_user.client_code = 'technician'`
  - 校验租户状态、账号状态
  - 复用 `LoginServiceImpl` 的密码校验、失败锁定、登录日志
  - 技师档案与在线状态在 M3 接入
- [ ] 当前用户 `POST /account/api/{client}/user/info`
  - 从 token session 读取 `userCode`、`tenantId`、`clientCode`
  - 返回 `UserInfoVO`
- [ ] 权限菜单 `POST /account/api/{client}/user/auth`
  - 返回当前用户的权限串集合与菜单树

- [ ] 退出 `POST /account/api/{client}/logout`
  - `StpUtil.logout()`
- [ ] 修改密码 `POST /account/api/{client}/password/change`
  - 参数：旧密码、新密码
  - BCrypt 校验旧密码，更新为新密码哈希
  - 修改成功后退出当前登录
- [ ] Mock 短信 `POST /account/api/{client}/sms/send`（可选，建议本期）
  - 固定验证码或日志输出

  - 若时间紧，可顺延到 M4 通知模块

### 4.2 RBAC 数据模型

- [ ] 在 `web/src/main/resources/db/h2-schema.sql` 增加四张表，字段与 `docs/sql/schema.sql` 对齐：
  - `sys_role`：`tenant_id`、`client_code`、`role_code`、`role_name`、`data_scope`、`status`、`is_system`
  - `sys_menu`：全局表，无 `tenant_id`，包含 `client_code`、`parent_id`、`perms`、`menu_type`
  - `sys_user_role`：`tenant_id`、`user_id`、`role_id`
  - `sys_role_menu`：`tenant_id`、`role_id`、`menu_id`
- [ ] 实体：
  - `SysRoleEntity extends TenantEntity`
  - `SysMenuEntity extends BaseEntity`（全局表，已在 `ignore-tables`）
  - `SysUserRoleEntity`、`SysRoleMenuEntity`：关联表没有 `update_by/update_time/remark/is_delete`，不要直接继承 `BaseEntity`；只映射 `id/tenant_id/user_id/role_id/create_by/create_time`，`tenant_id` 字段加 `@Column(tenantId = true)`
- [ ] Mapper：`SysRoleMapper`、`SysMenuMapper`、`SysUserRoleMapper`、`SysRoleMenuMapper`
- [ ] 种子数据：
  - 平台管理员角色 + 平台全部权限

  - 租户普通用户角色

## 6. 风险与注意事项

- 权限缓存不在本里程碑，M2 每次鉴权查库是可接受的；不要在 M2 引入半成品缓存。
- `sys_menu` 是全局表，不要加 `tenant_id`；`sys_role` 和关联表是租户表。
- 技师登录只做账号认证，技师档案、接单权限在 M3 落地。
- 修改密码后要退出当前 token，避免旧密码会话继续使用。
- 新增权限串时必须同步种子数据，否则本地测试无法通过。
- 不要在 Controller 手写“是否管理员”判断，统一走 `@SaCheckPermission` 和数据范围。
