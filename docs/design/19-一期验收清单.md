# 一期验收清单（附录 B）

> 所属：[总体设计](00-总体设计.md) · 原文附录：附录 B

- [ ] 两个租户的数据完全隔离，按 uid 枚举也查不到对方数据
- [ ] 平台端可以跨租户查询，且操作日志有记录
- [ ] 登录失败 5 次锁定 15 分钟
- [ ] token 30 天有效，剩余 <30 分钟自动续期
- [ ] 无权限接口返回 403
- [ ] 工单状态机覆盖所有合法流转，非法流转返回 400
- [ ] 100 并发接单只成功 1 个
- [ ] 同一个 `requestId` 重复创建只产生 1 条工单
- [ ] 消费者宕机后消息重试，超过次数进 `msg_fail`
- [ ] 重复 MQ 消息只处理一次
- [ ] 超时任务重复执行不会重复提醒
- [ ] 1 万条工单导出不 OOM，文件可下载
- [ ] 手机号库里是密文，接口返回是掩码
- [ ] 查看手机号明文会写审计日志
- [ ] 每个请求日志都有 traceId，能串起 HTTP → MQ
- [ ] `docker compose up` 一条命令起全套
- [ ] CI 跑通单元测试 + 集成测试
