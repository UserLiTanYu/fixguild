# 16. 配置与环境

> 所属：[总体设计](00-总体设计.md) · 原文章节：§16

## 16.1 Profile

| Profile | 用途 |
|---|---|
| `local` | 本地开发（显式指定），H2 内存库 |
| `dev` | 本地开发（默认）/联调，MySQL |
| `test` | CI/集成测试，H2 |
| `prod` | 生产，环境变量 |

## 16.2 环境变量

```text
DB_URL=jdbc:mysql://localhost:3306/fixguild?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
DB_USERNAME=lty
DB_PASSWORD=change-me
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=
ROCKETMQ_NAME_SERVER=localhost:9876
MINIO_ENDPOINT=http://localhost:9000
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin
XXL_JOB_ADMIN_ADDRESSES=http://localhost:8088/xxl-job-admin
```

> 所有密钥走环境变量或 `.env`，`.env` 加入 `.gitignore`。不要复制原项目的真实配置。

## 16.3 Docker Compose

建议服务：

```yaml
services:
  mysql:
    image: mysql:8.4
    ports: ["3306:3306"]
  redis:
    image: redis:7
    ports: ["6379:6379"]
  rocketmq-namesrv:
    image: apache/rocketmq:5.3.1
    ports: ["9876:9876"]
  rocketmq-broker:
    image: apache/rocketmq:5.3.1
    ports: ["10911:10911"]
  rocketmq-console:
    image: apacherocketmq/rocketmq-dashboard:latest
    ports: ["8080:8080"]
  minio:
    image: minio/minio:latest
    ports: ["9000:9000", "9001:9001"]
  xxl-job-admin:
    image: xuxueli/xxl-job-admin:2.4.1
    ports: ["8088:8080"]
```

> 版本按你本机实际情况调整；RocketMQ 5.x 与 4.9.x 的配置差异较大，先选一个跑通。
