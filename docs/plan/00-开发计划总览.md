## 3. Definition of Done

一个任务只有满足以下条件才算完成：

- [ ] 代码通过 `mvn test`
- [ ] 新接口有 Swagger 注解
- [ ] 涉及租户数据的接口有隔离测试
- [ ] 涉及权限的接口有 403 测试
- [ ] MySQL 与 H2 的 schema 字段、索引、默认值一致
- [ ] `docs/design/api-examples.http` 已更新
- [ ] 本计划中对应任务已勾选
- [ ] 里程碑结束时更新根 `README.md` 与 `docs/README.md`

## 4. 进度维护

- 本目录的复选框是**唯一开发进度源**。
- 根 `README.md` 和 `docs/README.md` 只保留里程碑级摘要，不重复维护任务清单。
- 每完成一项任务，直接勾选对应文档；里程碑完成后更新本页总表。
- 发现范围变化时，先改计划文档，再改代码。
- 已知偏离项记录在 [18-风险与待定项](../design/18-风险与待定项.md)。
