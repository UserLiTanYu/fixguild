| 原项目 | 你的实现 | 学习点 |
|---|---|---|
| `common/config/MyTenantFactory.java` | `TenantContext` + `MyTenantFactory` | 多租户插件、请求级隔离 |
| `common/filter/SaTokenAuthInterceptor.java` | `AuthInterceptor` | 多端登录、token 续期、MDC |
| `account/config/StpInterfaceImpl.java` | `StpInterfaceImpl` + `AuthService` | RBAC、权限缓存 |
| `common/config/RocketMQProducer.java` | `EventPublisher` | 事务后发送、失败落表 |
| `common/baseinterface/AbstractRocketMQConsumer.java` | 同款基类 | 泛型消费、重试、幂等 |
| `common/annotation/DistributedLock.java` + AOP | 同款 | 声明式锁、SpEL |
| `common/aspect/ExportSessionAspect.java` | `ExportTaskService` | 异步导出、任务表 |
| `common/annotation/EncryptedField.java` + `Sm4TypeHandler` | 同款 | 字段加密、TypeHandler |
| `common/utils/crypto/MaskingSerializer.java` | 同款 | 脱敏输出 |
| `common/filter/TraceIdFilter.java` | 同款 | 链路追踪 |
| `common/service/I*ProviderService` | 同款 | 模块解耦 |
| `.claude/skills/code-crud/SKILL.md` | 自己的 CRUD 模板 | 代码规范 |

## 读原项目的 4 条链路

1. **登录鉴权**：`PlatformLoginController` → `LoginServiceImpl` → `AuthServiceImpl` → `StpInterfaceImpl` → `SaTokenAuthInterceptor`
2. **CRUD**：`OrderChildController#page` → `OrderChildServiceImpl` → `OrderChildDao` → `OrderChildMapper` → SQL
3. **MQ**：`RocketMQProducer` → `WebConsumer` / `DatacenterConsumer` → `AbstractRocketMQConsumer` → `msg_fail`
4. **定时任务**：`GoodsSourceQuoteJob` / `OrderChildWeightAuditJob` → XXL-Job

## 读代码时做的实验

- 新增一个租户，验证数据隔离；
- 把 `MyTenantFactory` 改成从登录态取 `tenantId`，写测试；
- 加一个 MQ 消费者，杀掉消费者看重试和失败表；
- 加一个 1 万条导出，观察内存和耗时；
- 给一个接口加权限，验证 403；
- 打开 MyBatis-Flex SQL 审计，找一条慢 SQL 并加索引。
