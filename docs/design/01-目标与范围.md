# 1. 目标与范围

> 所属：[总体设计](00-总体设计.md) · 原文章节：§1

## 1.1 业务目标

为维保公司提供一个多租户 SaaS 工单平台：

- 平台方：管理租户、查看全局数据、配置全局字典；
- 租户方：管理自己的客户、设备、技师、工单；
- 技师：接单、上门、完工、上传现场照片；
- 客户（二期）：报修、确认完工、评价。

核心闭环：

```text
创建工单 → 派单 → 接单 → 到场/开始 → 完工 → 确认 → 评价
                ↘ 拒单 → 回到待派单
                ↘ 取消
```

## 1.2 技术目标

通过这个项目练到：

- Maven                      多模块 + Spring Boot 多环境；
- MyBatis-Flex：        分页、复杂查询、逻辑删除、审计字段、多租户插件；
- Sa-Token：              多端登录、RBAC、注解鉴权、Redis 会话、续期；
- Redisson：              声明式分布式锁、并发控制；
- RocketMQ：            可靠生产、泛型消费、重试、失败表、幂等；
- XXL-Job：                 超时扫描、自动确认、统计任务；
- Caffeine + Redis： 本地缓存 + 分布式缓存 + 版本号失效；
- Excel 导入导出：    异步导出、分页查询、对象存储；
- 数据安全：              SM4 加密、脱敏、查看审计；
- 可观测：                  traceId、慢 SQL、Actuator、Prometheus。

## 1.3 一期范围

| 模块                        | 一期是否做 | 说明                           |
| --------------------------- | ---------- | ------------------------------ |
| 平台端：租户管理            | ✅          | 租户 CRUD、启停                |
| 平台端：全局字典            | ✅          | 字典类型/数据                  |
| 平台端：全局工单查询        | ✅          | 跨租户查询，需 `@IgnoreTenant` |
| 租户端：用户/角色/菜单      | ✅          | RBAC                           |
| 租户端：技师/客户/设备      | ✅          | 基础档案                       |
| 租户端：工单全流程          | ✅          | 创建、派单、取消、确认、重开   |
| 技师端：接单/拒单/开始/完工 | ✅          | 核心闭环                       |
| 工单日志/附件               | ✅          | 时间线、现场照片               |
| MQ 通知                     | ✅          | 站内信 + Mock 短信             |
| 超时任务                    | ✅          | SLA 提醒、自动确认             |
| 异步导出                    | ✅          | 工单导出                       |
| 操作日志/登录日志           | ✅          | AOP + 表                       |
| 敏感数据加密/脱敏           | ✅          | 手机号、身份证号               |
| 客户 H5 报修/评价           | ⏳ 二期     | 先留接口和表                   |
| 服务费结算/发票             | ⏳ 二期     | 领域复杂，先不做               |
| 自动派单算法                | ⏳ 二期     | 一期手动派单                   |
| 工作流引擎                  | ❌          | 用状态机就够                   |
| 微服务拆分                  | ❌          | 模块化单体                     |

## 1.4 非目标

- 不做真实的支付、发票、银行对接；
- 不做复杂的风控规则引擎；
- 不做多语言、多币种；
- 不做大规模分布式事务；
- 不追求高并发，先追求**正确、可维护、可观测**。
