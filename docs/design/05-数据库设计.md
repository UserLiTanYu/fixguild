# 6. 数据库设计

> 所属：[总体设计](00-总体设计.md) · 原文章节：§6 + 附录 A

## 6.1 统一约定

| 约定 | 说明 |
|---|---|
| 主键 | `id BIGINT UNSIGNED AUTO_INCREMENT` |
| 业务 ID | `uid VARCHAR(32)`，全局唯一，对外暴露 |
| 租户 | `tenant_id VARCHAR(32) NOT NULL`，平台为 `'0'` |
| 审计 | `create_by`、`update_by`、`create_time`、`update_time` |
| 逻辑删除 | 业务主表 `is_delete TINYINT NOT NULL DEFAULT 0`；日志/关联/幂等表可物理删除 |
| 乐观锁 | 核心表加 `version INT NOT NULL DEFAULT 0` |
| 主键类型 | 建议 `BIGINT`；原项目用 `Integer`，如严格对齐可改 `Integer` |
| 字符集 | `utf8mb4` / `utf8mb4_0900_ai_ci` |
| 时间 | `DATETIME`，Java 用 `LocalDateTime` |
| 金额 | `DECIMAL(12,2)`（二期） |
| 外键 | 不用数据库外键，靠应用保证 |
| 枚举 | 数据库存字符串或 tinyint，Java 用 enum |

## 6.3 关键表说明

### `work_order`

最重要的表，字段分四组：

- 基本信息：`order_no`、`title`、`description`、`priority`、`source`
- 关联信息：`customer_id`、`equipment_id`、`technician_id`、`dispatcher_id`
- 时间信息：`expect_time`、`assign_time`、`accept_time`、`start_time`、`finish_time`、`confirm_time`、`cancel_time`
- 控制信息：`status`、`version`、`timeout_flag`、`timeout_notify_time`

索引：

- `uk_tenant_order_no (tenant_id, order_no)`：租户内单号唯一；
- `idx_tenant_status (tenant_id, status)`：列表页主查询；
- `idx_tenant_technician_status (tenant_id, technician_id, status)`：技师端；
- `idx_tenant_customer (tenant_id, customer_id)`：客户维度；
- `idx_tenant_expect (tenant_id, expect_time, status)`：超时扫描。

### `work_order_log`

工单时间线，所有状态变更必须写一条：

- `action`：`CREATE/ASSIGN/ACCEPT/REJECT/START/COMPLETE/CONFIRM/CANCEL/REOPEN`
- `from_status`、`to_status`
- `operator_id`、`operator_name`、`operator_type`
- `trace_id`：方便和日志、MQ 串起来

### `work_order_command`

请求幂等表：

- 唯一键 `(tenant_id, request_id)`；
- 命令开始前插入，状态 `PROCESSING`；
- 成功后更新 `SUCCESS`，失败更新 `FAILED`；
- 重复请求直接返回已有结果，避免重复派单、重复完工。

### `work_order_dispatch`

派工历史：

- 一个工单可以多次派工（拒单后重派）；
- `status`：`PENDING/ACCEPTED/REJECTED/CANCELED`；
- 保留每次派工的技师、派单人、时间、拒绝原因。

## 6.4 查询与分页

- 列表页默认按 `create_time DESC, id DESC`；
- 关键字搜索 `order_no/title/customer_name`，客户名需要冗余到工单表或联表；
- 建议在 `work_order` 冗余 `customer_name`、`equipment_name`、`technician_name`，避免列表页多表 join；
- 数据量大时，列表页只查主表，详情再查关联表；
- 深分页用 `id < lastId` 的游标方式，管理端普通分页用 `LIMIT offset`。
