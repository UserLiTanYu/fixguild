# 13. 文件与导出

> 所属：[总体设计](00-总体设计.md) · 原文章节：§13

## 13.1 文件上传

推荐**预签名直传**，避免大文件过应用：

1. 客户端 `POST /api/file/presign`，传 `fileName/contentType/bizType`；
2. 服务端返回 `uploadUrl/fileKey/expiresIn`；
3. 客户端直接 PUT 到 MinIO；
4. 客户端 `POST /api/file/confirm`，服务端保存元数据。

约束：

- 单文件最大 20MB；
- 只允许 `jpg/jpeg/png/webp/pdf`；
- 文件 key 随机生成，不暴露原始路径；
- 私有桶，下载用 15 分钟预签名 URL；
- 图片可接内容审核（二期，Mock）。

## 13.2 Excel 导入

- 技师/客户/设备支持批量导入；
- 使用 EasyExcel/Fesod 流式读；
- 逐行校验，收集错误行；
- 批量插入，每批 500 条；
- 返回成功数、失败数、错误行下载地址；
- 导入任务也走异步，避免请求超时。

## 13.3 异步导出

- 创建 `export_task`，状态 `PENDING`；
- 异步线程池执行：
  - 更新 `RUNNING`；
  - 分页查询，每页 2000 条；
  - 写 Excel（SXSSF/EasyExcel）；
  - 上传 MinIO；
  - 更新 `SUCCESS` + `fileKey`；
- 前端轮询状态；
- 下载用预签名 URL；
- 失败记录 `error_msg`，可重试；
- 导出上限 10 万条，超过提示缩小范围。
