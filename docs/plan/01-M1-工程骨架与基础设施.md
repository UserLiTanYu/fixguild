## 1. 目标

建立可运行、可测试、可扩展的多模块工程骨架，为后续登录、工单、消息、文件等能力提供统一基础设施：

- 统一响应、异常、分页；
- 每个请求有 traceId；
- 数据库访问统一走 MyBatis-Flex；
- 多租户插件与审计字段可工作；
- 有一套可验证的租户 CRUD；
- 本地 H2 与 Docker MySQL 两套环境都能启动；
- Swagger 可访问，测试可执行。

---

## 2. 范围

### M1 已完成

- Maven 四模块骨架：`common`、`account`、`core`、`web`
- Docker Compose：MySQL、Redis、MinIO
- 统一响应 `CommonResponse<T>`、分页参数 `PageParam`、分页结果 `PageResult<T>`
- 全局异常处理 `GlobalExceptionHandler`
- `TraceIdFilter`：请求级 traceId、MDC、响应头
- MyBatis-Flex：分页、逻辑删除、审计字段、SQL 审计、慢 SQL 日志
- 多租户骨架：`TenantContext`、`MyTenantFactory`、`@IgnoreTenant`
- `sys_tenant` 完整 CRUD：分页、新增、编辑、详情、启停
- springdoc OpenAPI + `/doc.html` 兼容跳转
- H2 `local` profile、MySQL `dev` profile、Maven Wrapper
- 租户 CRUD、参数校验、重复键、健康检查、traceId、`@IgnoreTenant` 测试
