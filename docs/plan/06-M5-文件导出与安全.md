# M5：文件导出与安全

> 里程碑：M5（第二部分）· 状态：未开始 · 预计 1 周  
> 关联设计：[12-文件与导出](../design/12-文件与导出.md) · [13-安全与审计](../design/13-安全与审计.md) · [14-异常日志与追踪](../design/14-异常日志与追踪.md)

---

## 1. 目标

完成现场照片、Excel 导入导出、操作审计和敏感数据保护：

- 文件走预签名直传，不经过应用服务；
- 工单导出异步执行，可轮询进度、预签名下载；
- 写操作有统一操作日志；
- 手机号、身份证号加密存储、脱敏输出、查看明文有审计。

---

## 2. 前置条件

- M3 工单与附件元数据完成；
- M4 通知链路稳定；
- M5 第一部分 Redis/锁完成（异步导出线程池会复用 `TaskDecorator`）；
- `docker-compose.yml` 已有 MinIO。

---

## 3. 范围

### 做

- MinIO 预签名上传与文件确认；
- 工单附件上传/下载；
- 技师/客户/设备 Excel 导入；
- 工单异步导出；
- 操作日志 AOP；
- SM4 加密、哈希索引、脱敏、查看明文审计。

### 不做

- 真实 OCR、图片内容审核（二期 Mock）；
- 客户 H5 上传；
- 结算/发票文件；
- 日志表分表归档（二期）。

---

## 4. 任务清单

### 4.1 MinIO 与文件上传

- [ ] 引入 MinIO SDK，配置 `endpoint/accessKey/secretKey/bucket`
- [ ] 私有桶；下载统一使用 15 分钟预签名 URL
- [ ] 文件预签名 `POST /api/file/presign`
  - 参数：`fileName/contentType/bizType`
  - 返回：`uploadUrl/fileKey/expiresIn`
- [ ] 文件确认 `POST /api/file/confirm`
  - 保存文件元数据：原始名、大小、类型、key、租户、上传人
- [ ] 约束：
  - 单文件最大 20MB
  - 只允许 `jpg/jpeg/png/webp/pdf`
  - 文件 key 随机生成，不暴露原始路径
- [ ] 工单附件：
  - 技师完工上传照片
  - 工单详情返回附件预签名下载地址
  - 下载校验租户与权限

### 4.2 Excel 导入

- [ ] 技师/客户/设备批量导入
- [ ] EasyExcel/Fesod 流式读，避免一次性加载
- [ ] 逐行校验：必填、长度、格式、枚举、租户内唯一
- [ ] 错误行收集，返回成功数、失败数、错误文件下载地址
- [ ] 批量插入，每批 500 条
- [ ] 导入任务异步执行，避免请求超时
- [ ] 导入结果记录 `export_task` 或独立导入任务表

### 4.3 异步导出

- [ ] `export_task` 表、实体、Mapper、Service
- [ ] 创建导出任务 `POST /tenant/api/work-order/export`
  - 保存查询条件、租户、创建人
  - 状态 `PENDING`
- [ ] 异步线程池：
  - 配置 `TaskDecorator`，传递 `TenantContext` 与 MDC
  - 更新 `RUNNING`
  - 分页查询，每页 2000 条
  - SXSSF/EasyExcel 写文件
  - 上传 MinIO
  - 更新 `SUCCESS` + `fileKey`
  - 失败更新 `FAILED` + `error_msg`
- [ ] 状态查询 `POST /api/export/task/status`
- [ ] 下载 `POST /api/export/task/download`，返回预签名 URL
- [ ] 上限 10 万条，超过提示缩小范围
- [ ] 导出恢复任务 `exportTaskRecoveryJob`：扫描长时间 `RUNNING` 的任务，重置或标记失败
- [ ] 导出内容脱敏：手机号、身份证号不得出现明文

### 4.4 操作日志

- [ ] `@Log(module="工单", action="派单")` 注解
- [ ] AOP 记录：
  - 租户、用户、client、URI、方法
  - 请求参数（脱敏）
  - 响应结果、耗时、IP、traceId
- [ ] 写 `sys_operate_log`
- [ ] 写操作全部记录；查询默认不记录
- [ ] 敏感查询（查看明文、平台跨租户查询）必须记录
- [ ] 日志写入失败不影响主流程

### 4.5 敏感数据

- [ ] `@EncryptedField` + `Sm4TypeHandler`

  - 注册/修改时同步维护
- [ ] `@SensitiveMask(MaskType.MOBILE)` + Jackson 序列化器

  - 写操作日志
- [ ] 日志、MQ、导出文件禁止出现明文
- [ ] 密钥走环境变量，`.env` 加入 `.gitignore`

---

## 6. 风险与注意事项

- 文件 key 必须随机，禁止用原始文件名拼接路径。
- 私有桶 + 预签名 URL，禁止公开读。
- 异步线程必须传递并清理 `TenantContext`、MDC。
- 导出分页查询要带租户条件，禁止导出全表。
- 加密字段不要参与模糊查询；模糊查询需求另设计。
- 脱敏必须在序列化层统一处理，不能靠前端。
- 操作日志参数脱敏，避免密码、token、完整手机号落库。
- MinIO 本地地址与生产地址分开配置，不要提交密钥。
