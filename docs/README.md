## 推荐阅读顺序

0. 动手前先看 **开发规范** 和 **评审清单**。
1. 入门：**01-目标与范围** → **02-技术栈与模块划分** → **03-领域模型** → **04-工单状态机**。
2. 数据与接口：**05-数据库设计** → **06-API设计** → **07-关键时序** → **08-多租户与权限**。
3. 平台能力：**09-异步消息与定时任务** → **10-并发幂等与事务** → **11-缓存设计** → **12-文件与导出** → **13-安全与审计** → **14-异常日志与追踪**。
4. 工程实践：**15-配置与环境** → **16-测试策略** → **17-与原项目的学习映射** → **18-风险与待定项** → **19-一期验收清单**。
5. 开发执行：从 **开发计划总览** 进入当前迭代 **M3-工单核心**。
